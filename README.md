# Функционал проекта 

1) Клиент может ознакомиться с каталогом автомобилей и выбрать подхоядщий по его критериям
2) Регистрация/вход - клиент использует логин и пароль для входа
3) После выбора автомобиля клиента переводят на сотрудника центра для дальнейшей консультации 
4) В дальнейшем к каждому сотруднику будет привязан определный клиент, если сделка успешна, сотруднику 
начисляется определенный процент к зарплате
